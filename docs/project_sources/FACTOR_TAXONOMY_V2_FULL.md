# 股价影响因素全景表 v2.0

## 0. v2.0 使用原则

这版表格用于后续国内量化系统的主框架。它不是单纯的“聊天分类”，而是面向后续落库、回测、事件抽取、公司暴露映射和信号评分的工程化分类。

### 主框架

| 编号 | v2.0 一级层            | 核心问题                                                       | 在系统中的作用                                     |
|------|------------------------|----------------------------------------------------------------|----------------------------------------------------|
| 1    | 经营与公司事件层       | 公司本身是不是变好了、变差了，或者发生了会改变公司价值的事件？ | 公司基本面因子、公司事件抽取、公司级风险识别       |
| 2    | 行业供需与产业链价格层 | 行业供给、需求、库存、价格、价差和竞争格局是否变化？           | 产业链因子、商品价格因子、行业景气因子             |
| 3    | 宏观流动性与政策国际层 | 大环境是否改变盈利中枢、流动性、风险偏好和政策方向？           | 宏观环境过滤、政策事件识别、外部冲击判断           |
| 4    | 资本市场制度与供需层   | 股票市场本身的制度、股票供给、资金供给是否变化？               | A 股制度因子、资金供需因子、指数/ETF/解禁/减持因子 |
| 5    | 交易行为与微观结构层   | 资金有没有真的交易这个逻辑？价格路径是否被资金强化或扭曲？     | 市场确认、短线风险、量价行为、异常交易识别         |
| 6    | 信息披露与舆情传播层   | 信息从哪里来，是真是假，传播多快，影响范围多大？               | 公告解析、新闻事件抽取、舆情监控、谣言过滤         |
| 7    | 预期、估值与定价偏离层 | 这个信息是否超预期？价格是否已经提前反应？估值是否透支？       | 预期差判断、估值分位、事件后漂移、风格拥挤         |
| 8    | 风险事件与合规边界层   | 有没有必须回避、降仓、冻结信号，或者不能合法使用的数据？       | 风控防火墙、合规过滤、黑天鹅/停牌/ST/处罚识别      |

## 1. 数据可得性等级

| 等级 | 含义                                     | 示例                                               | 系统处理方式                   |
|------|------------------------------------------|----------------------------------------------------|--------------------------------|
| A    | 公开、结构化、较容易获取，适合直接量化   | 股价、成交量、财报、公告、期货价格、宏观数据       | 可直接入因子库和回测           |
| B    | 公开但滞后、分散或需要清洗               | 基金持仓、股东人数、行业月报、海关数据             | 可用于中期因子或事件确认       |
| C    | 公开但高度分散，需要爬虫、NLP 或代理变量 | 地方新闻、招投标、处罚公告、社媒舆情、招聘信息     | 可进入事件库，但需要置信度评分 |
| D    | 不能直接拿，只能用替代指标逼近           | 真实订单、渠道库存、大客户流失、产能利用率         | 只作为低置信度代理信号         |
| E    | 不应获取或不可合法使用                   | 内幕合同、未披露并购、未公开监管决定、私域内幕消息 | 禁止进入实盘信号               |

## 2. 跨层元数据字段

无论属于哪一层，每个因素都应该附带这些字段。

| 字段               | 含义         | 示例                                                  |
|--------------------|--------------|-------------------------------------------------------|
| factor_id          | 因子唯一编号 | steel_iron_ore_price_up                               |
| layer              | 所属一级层   | 行业供需与产业链价格层                                |
| second_level       | 二级分类     | 上游原材料价格                                        |
| factor_name        | 因子名称     | 铁矿石价格上涨                                        |
| impact_path        | 影响路径     | 原材料成本上升 → 毛利率下降 → 利润预期下降            |
| affected_entities  | 影响对象     | 外购铁矿石比例高的钢企                                |
| direction_rule     | 方向规则     | 对钢企偏利空，对铁矿资源企业偏利好                    |
| time_horizon       | 影响周期     | 短期 / 中期 / 长期                                    |
| data_sources       | 数据源       | DCE、SHFE、巨潮、国家统计局、公司公告                 |
| data_availability  | 数据可得性   | A/B/C/D/E                                             |
| proxy_variables    | 替代变量     | 期货主力价格、库存、价差、新闻热度                    |
| lag_days           | 数据滞后     | 0 天、1 天、月度滞后                                  |
| confidence_default | 默认置信度   | 0.75                                                  |
| backtestable       | 是否适合回测 | true / false / partial                                |
| compliance_flag    | 合规状态     | public_data / rumor_only / restricted / illegal       |
| trade_usage        | 交易用途     | factor_signal / risk_filter / observe_only / no_trade |

## 13. 信号评分 v2.0

单个事件或因子不直接输出“买入/卖出”，而是输出四个分数。

| 分数                | 含义                                           | 主要来源                             |
|---------------------|------------------------------------------------|--------------------------------------|
| real_impact         | 对真实经营、供需、成本、利润的影响             | 公司经营层、行业产业链层、宏观政策层 |
| market_confirmation | 市场是否已经用价格、成交量、期货、板块确认     | 交易行为与微观结构层                 |
| sentiment           | 信息传播热度与情绪方向                         | 信息披露与舆情传播层                 |
| confidence          | 来源权威度、抽取稳定性、公司映射完整度、合法性 | source_registry + compliance_rule    |

建议总分：

    signal_score = 0.40 * real_impact
                 + 0.30 * market_confirmation
                 + 0.10 * sentiment
                 + 0.20 * confidence

决策分档：

| 档位     | 条件                                       | 行动                 |
|----------|--------------------------------------------|----------------------|
| 仅观察   | 非公开、传闻、置信度低、无市场确认         | observe_only         |
| 模拟交易 | 公开信息，真实影响较强，但市场确认不足     | paper_trade          |
| 小额实盘 | 公开信息，真实影响强，市场确认强，合规通过 | manual_confirm_trade |
| 禁止交易 | 内幕/受限/无法审计来源                     | no_trade             |

## 14. v2.0 结论

正式采用：

    8 个一级因素 v2.0 = 系统主框架 / 数据库主分类 / 建模骨架
    12 个基础因素 = 分析检查清单 / 防止遗漏现实来源

v2.0 的核心升级：

1.  把公司基本面和公司事件合并为 **经营与公司事件层**。
2.  把产业链层明确为 **供给、需求、库存、价格、价差、竞争格局**。
3.  把宏观层拆成 **宏观景气、流动性、财政地产、产业政策、汇率利率、国际贸易地缘**。
4.  保留并强化 **资本市场制度与供需层**，这是 A 股特色核心层。
5.  把资金行为扩展为 **交易行为与微观结构层**。
6.  把舆情和预期差彻底拆开：舆情归信息传播，预期差归定价偏离。
7.  把“黑天鹅”改成 **风险事件与合规边界层**，让它可以进入系统风控。
8.  增加跨层元数据：数据来源、合法性、滞后、置信度、公司映射、是否可回测。

后续所有行业样板表，例如钢铁、煤炭、石化、新能源、半导体，都应按这个 v2.0 框架展开。
